## CLI tools
---

1. [Xcode Command Line Tools](https://mac.install.guide/commandlinetools/) `xcode-select --install` it comes with `clang`, `gcc`, `clang++`, `g++`, `git` and more.

   **List of Xcode Command Line Tools**

   ```
   ls /Library/Developer/CommandLineTools/usr/bin/
   ```

2. [Homebrew](https://brew.sh/) is a **free and open-source software package management system** that simplifies the installation of software on macOS, as well as Linux.

3. [Git](https://git-scm.com/) already comes with Xcode CLT.

4. [uv](https://github.com/astral-sh/uv) is a **fast Python package installer and resolver**. `brew install uv`

5. [opencode](http://opencode.ai/) is an **open source agent** that helps you write code in your terminal, IDE, or desktop. `brew install anomalyco/tap/opencode`

6. [kitty](https://sw.kovidgoyal.net/kitty/) is a **fast, feature-rich, GPU based terminal emulator**. (Ansi colors support, smooth scrolling, kittens, terminal multiplexer, etc.) `brew install kitty`

7. [tmux](https://tmuxcheatsheet.com) (short for Terminal Multiplexer) is a command-line tool that lets you manage multiple terminal sessions within a single window. `brew install tmux`

8. [htop](https://htop.dev/) is a **free and interactive process viewer** for Unix systems. `brew install htop`

9. [Gen CLI](https://github.com/iamprasadraju/gen-cli) (my own CLI tool) `pip install gen-cli`

## Applications

---

1. [brave Browser](https://brave.com/) `brew install --cask brave-browser`
2. [OBS](https://obsproject.com/) **free and open source software** for video recording and live streaming. `brew install --cask obs`
3. [Zed](https://zed.dev/) is a **Rust based code editor**. `brew install --cask zed`

4. [devin](https://windsurf.com/) is a **free and open-source code editor** (for unlimited inline autocomplete, LEAN infoview). `brew install --cask devin-desktop`
5. [Discord](https://discord.com/) is a **free voice and text communication application**. `brew install --cask discord`
6. [Spotify](https://open.spotify.com/download) is a **popular digital audio streaming service** for music listening. `brew install --cask spotify`
7. [Obsidian](https://obsidian.md/) **stores notes privately** on your device as markdown files. `brew install --cask obsidian`
8. [Rstudio](https://posit.co/download/rstudio-desktop/) is a **free and open-source integrated development environment** for the R programming language. `brew install --cask rstudio`
9. [lidless](https://github.com/nghialuong/Lidless) A tiny macOS menu-bar app that keeps your Mac running even with the lid closed.
10. [Battery Toolkit](https://github.com/mhaeuser/Battery-Toolkit) lets you set a hard limit past which battery charging turns off on Apple Silicon Macs.
11. [MacDroid](https://apps.apple.com/us/app/macdroid-manager-for-android/id1476545828?mt=12) the **ultimate solution for transferring files** between Android and Mac.
12. [Rectangle](https://rectangleapp.com/) **move and resize windows** in macOS using keyboard shortcuts or snap areas. `brew install --cask rectangle`
13. [Mos](http://mos.caldis.me/) is a **free, open-source macOS utility** that makes wheel scrolling feel closer to a trackpad. `brew install --cask mos`
14. [BetterDisplay](https://betterdisplay.pro/) is a **macOS utility that allows you to customize your display settings** (external display). `brew install --cask betterdisplay`

## Python Libraries

---

1. [Numpy](https://numpy.org/doc/stable/) the **fundamental package for scientific computing** with Python. `pip install numpy`
2. [Pandas](https://pandas.pydata.org/docs/) is a **fast, powerful, flexible and easy to use open source data analysis and manipulation tool**. `pip install pandas`
3. [Scikit-learn](https://scikit-learn.org/stable/user_guide.html) is an **open source machine learning library** for supervised and unsupervised learning. `pip install scikit-learn`
4. [Seaborn](https://seaborn.pydata.org/index.html) is a **Python data visualization library** based on matplotlib. `pip install seaborn`
5. [Matplotlib](https://matplotlib.org/) is a **comprehensive library for creating static, animated, and interactive visualizations** in Python. `pip install matplotlib`
6. [Pytorch](https://docs.pytorch.org/docs/stable/index.html#) is an **open-source optimized tensor library** for deep learning using GPUs and CPUs. `pip install torch`
7. [Tensorflow](https://www.tensorflow.org/api_docs) is an **open-source, end-to-end machine learning platform** developed by Google. `pip install tensorflow`
8. [Scipy](https://docs.scipy.org/doc/scipy/) is a **collection of mathematical algorithms and convenience functions** built on NumPy. `pip install scipy`
9. [Jupyter Notebook](http://jupyter.org/) is the **web-based interactive development environment** for notebooks, code, and data. `pip install notebook`
10. [OpenCV](https://docs.opencv.org/4.x/) is a **library of programming functions** mainly for real-time [computer vision](https://en.wikipedia.org/wiki/Computer_vision). `pip install opencv-python`
11. [ty](https://github.com/astral-sh/ty) An extremely fast Python type checker and language server, written in Rust. `pip install ty`
12. [ruff](https://docs.astral.sh/ruff/) A Python linter, written in Rust. `pip install ruff`
13. [prek](https://prek.dev/) is an ultra-fast, Rust-powered Git hook manager that serves as a single-binary, drop-in replacement for the classic Python pre-commit framework. `pip install prek`
14. [pytest](https://docs.pytest.org/en/stable/) A Python testing framework. `pip install pytest`
15. [tqdm](https://tqdm.github.io/) A fast, extensible progress bar for Python and CLI. `pip install tqdm`
